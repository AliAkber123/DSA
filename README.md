# DSA Practice Journal (Python)

A pattern-based, GitHub-ready DSA practice repository inspired by a 16-topic DSA mind map. The goal is **~80% coding practice and ~20% explanation/review**.

## Quick start
1. Open this folder in **VS Code** and make sure Python is installed.
2. Start with `01_arrays/001_running_sum.py`.
3. Run from the VS Code Terminal: `python 01_arrays/001_running_sum.py` (Windows users may use `py` instead of `python`).
4. Tests intentionally fail at first; replace `raise NotImplementedError(...)` with your code.
5. Re-run until tests pass; write a brief approach and complexity at the top of your solution.
6. Check off the item in `PROGRESS.md`, then commit your work.

## Consistent file naming
`001_running_sum.py`, `002_maximum_subarray.py`, etc. Place files in the relevant topic folder; keep the number unique **within that folder**.

## Practice workflow (one problem at a time)
- Read the problem, inputs/outputs and constraints (3–5 minutes).
- Try your own idea and code without looking at a full solution (20–30 minutes).
- If stuck, get a targeted hint, then finish and test.
- Summarize the recognized pattern + time and space costs.
- Retry without notes after 2 days, then 7 days.

## Upload to GitHub from VS Code (first time)
1. Open **Source Control** on the left (`Ctrl+Shift+G`).
2. Choose **Initialize Repository** (requires Git installed).
3. Stage all files with **+**, enter a message such as `Initialize DSA practice repo`, and select **Commit**.
4. Open Command Palette (`Ctrl+Shift+P`) and choose **Publish to GitHub**; sign in and select Public or Private.
5. Subsequent sessions: after saving files, **stage → commit → Sync Changes / Push**.

Never commit passwords, API keys or private data.

## How to get help
Share your `.py` file or error output. Ask for **a hint first**; request a full solution only after trying.
